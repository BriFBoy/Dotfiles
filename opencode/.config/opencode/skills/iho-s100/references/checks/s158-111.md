### 111_1002 [Error] Mandatory or conditionally mandatory General Metadata attribute missing or of wrong value type
- **Dev ID:** S111_Dev1002
- **Check Description:** FOR EACH attribute in General Metadata with multiplicity lower bound = 1 or lower bound conditionally = 1, WHERE an HDF5 attribute with the identical camel case name and value type does not exist in the root group
- **Check Solution:** Add missing general metadata attribute
- **Standards document reference:** PS
- **Clause reference:** Table 12.1
- **Data Quality Measure:** Logical Consistency / Format Consistency OR Conceptual Consistency
- **Introduced:** 1.2.0
- **Old Dev ID (Internal use):** P1-5
- **Remarks (internal use):** For S-158:104 Ed 1.0, not all required/conditionally required/optional General Metadata attributes are included as separate checks. Instead, this check is an overarching check for required or conditionally required General Metadata attributes missing or of wrong type. 

TWCWG discussion to occur for best way to implement conditionally mandatory attribute checks.

All group, attribute and dataset name checks are case-sensitive.

Not found: format consistency;
Wrong datatype or value: conceptual consistency
- **S-100 Ed 5.2.0 reference (internal use):** N/A
