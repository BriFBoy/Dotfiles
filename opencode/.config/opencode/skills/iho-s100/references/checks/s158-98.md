### 98_1001 [W] Horizontal datum incompatibility
- **Dev ID:** S98_Dev1005
- **Check Description:** Datasets with overlapping coverages should use compatible CRSs in the region of overlap, preferably based on the WGS 84 datum
- **Check Solution:** Use datasets with compatible CRSs (which does not necessarily mean  identical CRS codes)
- **Standards document reference:** S-98; S-98 Annex A; S-100 Part 10c
- **Clause reference:** [D-1, D-2, D-3]; [5]; [Table 10c-6]
- **Introduced:** 1.8.0
- **Products:** All
- **Inputs:** Dataset

## Sheet: OverlapNotes

- Note No. | Note
- 1 | Successive forecasts or predictions for the same area may cover overlapping (but not coincident) time periods.
- 2 | For gridded data, cells with fill values may overlap cells with actual data or fill values.
- 3 | Since bounding box coordinates are generally approximate, an overlap of 0.01 degrees is permissible for bounding boxes.
- 4 | For vector data, regions with no data coverage may overlap either regions with or without data coverage.

## Sheet: DataDynamicity

- Code | Label | Description | Notes
- 2 | astronomicalPrediction | Values computed using harmonic analysis or other proven method of tidal analysis | Codes, labels and descriptions are from S-104 Ed. 2.0.0
- 3 | analysisOrHybrid | Values calculated by statistical or other indirect methods, or a combination of methods
- 5 | hydrodynamicForecast | Values calculated from a two- or three-dimensional dynamic simulation of future conditions using predicted data for boundary forcing, via statistical method or combination

## Sheet: Datums

- Note No. | Note
- 1 | If the gridded dataset contains features using different vertical datums, grid cells outside the corresponding domain extent polygon are ignored when the gridded feature is checked.
